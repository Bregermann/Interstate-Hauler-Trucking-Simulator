# Truck Fishing

A stationary truck, a real woven oval net, and a shared seeded river challenge. One to four total participants; AI never consumes a human pane. Move only left/right with the assigned keyboard cluster, whole-controller left stick, or independently owned shared stick. No launch/action button. The setup retains names, colors, source ownership and independent AI difficulty through rematches.

Small orange fish are1lb; blue tuna5lb. Missing them adds the same missed weight;20lb missed eliminates. Violet shark /white X is poison: catching eliminates; passing safely adds nothing. The net opening is the catch area. Catch resolution sweeps the crossing fraction against the moving net, resolves each delivery ID once and batches final eliminations before last-survivor/draw decisions. Solo survival has no time or200lb cap and retains local survival/caught personal bests.

The identical director schedule supplies every stream. Fish do not home toward nets. It has a gentle opening, peaks, schools, poisonous sections, lulls, recovery breaks and capped long-run difficulty. Consecutive good-fish spacing uses the actual arrival gap. Exposed defaults include2.8–4.5m/s nominal speed,4.5–8.5s visible travel,12% acceleration ramp,600s challenge cap, bounded density,5s burst and3s break. Net speed8.5m/s, acceleration42m/s², catch radius1.1m. AI uses visible fish only, the same net acceleration/speed and imperfect difficulty-dependent prediction/reaction.

Authoring: `LWS.TruckFishing.Editor.FishingAuthoring.Create`. Saved scene: `Assets/TruckFishing/Scenes/TruckFishing.unity`. The menu entry and explicit combined build workflow retain it on regeneration. Never run the old CreateValidateBuild over upgraded sports.

Presentation uses licensed Layer Lab3D Characters-Fish models and actual swimming clips through owned URP variants, an authored persistent oval hoop/diamond net/wood handle/binding, continuous textured river terrain, installed grass/rock models and pooled catch splashes. Fishing uses a small shallow-water URP Lit material adapter with the installed River Modeler normal map and DOTween flow. Native render comparisons found its depth-dependent full river graph disappearing against this fixed orthographic riverbed; the Bog graph remains unchanged. Inherited emission keyword and GI flags are explicitly cleared. Per-stream material instances restore their originals on disable, preventing missing-material errors on reactivation. There is no replacement water simulation or vendor source edit.

Pause/reconnect freezes fish, net, clock and score. Explicit replacement requires neutral/fresh input. Elimination keeps viewport layout stable. Full controls, setup and modal screens use the collection's Heat/uGUI shared components and settings.

Required licensed import: Layer Lab3D Characters-Fish1.0.2, product282104.
