## Gameplay

Two input banks use existing owned axes/ACTION: POSTURE integrates pitch/lean; TURN/LIFT adjusts held turn rate and elevation. Digital keyboards can settle at every target rather than being limited to zero/full angular speed. Switching to POSTURE stops a turn. AI uses the same bounded axes, rate limits and observed pose feedback.

The mode has one stationary kinematic exhibition pose authority, as already established in Yoga/Dance. `BalletTruckRig` alone moves the original Rigidbody and attached physical Cab offsets in fixed steps. No second Yoga/Dance pose component is attached. Original source hierarchy, wheel transforms/controllers, collider geometry and vehicle settings remain intact; powered driving is disabled during the performance. All selected bodies, wheels and costume stay coherent under full-assembly yaw.

**Explicit presentation limitation:** this is theatrical whole-assembly plié/lean, not a literal powered NWH suspension/balance simulation. The minimum original tire-envelope clearance is applied by that same pose authority. Player-controlled lift is measured separately from the derived clearance. The giant tutu has only a bounded render-only hem compression at the stage; it does not alter physics or implement a general cloth framework. Source mesh, UVs and materials remain intact, and runtime mesh ownership is released. This limitation is also stated in player Help rather than claiming a new suspension simulation.

Scores read actual prior fixed-step pitch, lean, lift, angular velocity and unwrapped heading. Spins require measured net turns (360/180/90degrees); the hop requires an achieved rise above1.05m followed by a controlled return. Hold1.8seconds rewards accuracy/stability; timing and smooth measured transitions contribute points. Each cue has18seconds, but timeout cannot manufacture completion. Ties remain tied. HUD displays actual/target values and the active control bank. Full results/rematch/pause/help use existing session flow. Score journal points are aggregated once per actual complete performance to avoid flooding preserved earned-point holds; each move's actual completion count remains an outcome and live HUD value.
