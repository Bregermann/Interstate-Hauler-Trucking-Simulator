# Truck Poker — offline no-limit Hold’em

The saved playable scene, collection entry and explicit sports-only scene list are integrated. Two–eight seated trucks play a virtual-chip tournament; up to four humans have independent driver views, with sequential private hot-seat handoffs also available. Remaining seats use independent Easy/Normal/Hard AI. The final combined Windows rebuild remains pending the rest of the queued production pass.

PokerTable owns deck/shuffle, blinds/button, betting streets, legal actions, full-raise/short-all-in reopening, runouts, settlement and tournament chip conservation. PokerHand selects the best five of five–seven cards, including the wheel. PokerPots resolves contribution bands, folded-hand ineligibility, ties, odd chips left of the button and uncalled returns. UI cannot inject a score. Solo-call action against a short all-in blind cannot invent a full-blind phantom call.

PokerPolicy receives only a copied PokerView for its own seat and an independent personal RNG. It has no table/deck/opponent-hand/future-shuffle reference. Difficulty changes samples, execution error and decisions; personality/bluffs do not read opponents’ private cards. Public snapshots cannot mutate the engine. Fold wins expose no hands; ordinary showdown tables required winners, while all-in showdowns table surviving hands. Own-pane hold-to-peek UI clears its card IDs, suit data, text, character metadata and mesh on release, pause, focus loss, source change and hot-seat handoff. Only required public showdown faces reach the world.

Betting follows the current [Poker TDA rules45/49](https://www.pokertda.com/view-poker-tda-rules/) for minimum full raises and cumulative short all-in reopening, retrieved2026-10-16. Incomplete opening all-ins do not reopen a previous checker without a full bet faced. Interface actions are explicit; physical chip-declaration ambiguity rules do not apply. This is offline play with virtual chips, no real-money services.

Vendor audit: no suitable installed or accessible owned poker rules engine was found in the existing asset audit. LWS therefore owns these missing game rules; existing Unity Input System, Heat/TMP, DOTween and canonical truck presentation provide the playable mode’s foundations. No vendor source modified.


Controls: assigned movement left/right selects Fold/Check-Call/Raise; forward/back adjusts the legal total; fresh assigned Action confirms. Min/half-pot/pot/all-in buttons select amounts without committing. Whole-pad LB peeks; shared-stick clicks peek only their owner; keyboard peek key is displayed per cluster. Hold right mouse for the explicitly assigned keyboard camera, or whole-pad right stick to look; middle mouse/right-stick click recenters. Shared sticks retain fixed cameras. Options preserve starting stacks, blinds, hand-based levels, sensitivity/invert and rematch setup.

Presentation uses the canonical render-only Taxi cockpit and NWH truck meshes, installed restaurant furniture, Heat/TMP fonts and UI, DOTween public reactions, and a selectively imported owned blonde ponytail (lowest956-vertex LOD) with bounded Unity Cloth. Dealer is a clearly adult pink truck in a fully clothed purple costume. Public gestures, cab look and peeking motions contain no hidden-strength signal. Public history, button/blind markers and chip stacks follow the authoritative table. No Poker replays record private hands.
