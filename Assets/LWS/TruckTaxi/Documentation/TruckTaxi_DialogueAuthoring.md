# Truck Taxi dialogue and cast authoring

In the Unity Editor, run **Truck Taxi > Passenger Factory Tools > Configure Requested Cast and Wobble Visuals** once after scripts compile. This creates only missing cast assets, adds missing jug/continuity text lines, builds unmodeled Wobble prefabs when needed, and registers the roster. It does not replace existing passenger dialogue or authored model assignments. Run it again safely after roster source changes. The source for the 29 requested IDs is `Tools/TruckTaxiPassengerFactory/requested-cast.json`.

Dialogue assets live in `Assets/LWS/TruckTaxi/Passengers/Dialogue/<PassengerStableID>.asset`. Open **Truck Taxi > Passenger Factory**, select a passenger, and use **OPEN DIALOGUE ASSET** to edit lines in the Inspector. The Factory's **OPEN DIALOGUE SOURCE FOLDER** opens the whole set.

For spreadsheet editing, use **EXPORT SELECTED DIALOGUE CSV** or **EXPORT ALL DIALOGUE CSV**. Files go to `Tools/TruckTaxiPassengerFactory/DialogueCSV/`. Edit the CSV there, preserving `PassengerID` and `LineID`, then use the matching **IMPORT SELECTED DIALOGUE CSV** or **IMPORT ALL DIALOGUE CSV** action. Selected import rejects rows for other passengers. Import validates the whole file before applying it; existing lines not mentioned remain untouched. Export asks before replacing an existing CSV, so import edits before re-exporting.

The CSV includes category, emotion, text, subtitle, weight, priority, cooldown, one-shot, tags, and generated-audio status. Editing text keeps any old audio clip but clears its generation hashes; export reports **STALE** and the existing **Regenerate Stale Audio** command can replace it later. No CSV action generates audio.

Generated voice clips live in `Assets/LWS/TruckTaxi/Passengers/GeneratedAudio/`; **OPEN GENERATED AUDIO** reveals that folder. Source reference WAVs belong outside the project at `F:/Codexprojects/MyVoiceForRecording/WorkHere/voice_refs/<PassengerStableID>__<tone>.wav`. Factory **SCAN VOICE REFERENCES**, **PREVIEW MATCHES**, and **AUTO-ASSIGN VOICE REFERENCES** use exact stable IDs and existing voice profiles; source WAVs are never changed. Do not use generation actions until the designer supplies references.

The new cast uses original names and voice metadata only. Wobble prefabs are stylized fallback art, not final character models or a claim of exact recovery of an earlier model. The cast setup has been executed: 114 registered profiles include all 24 requested adult glam IDs and five original racing IDs. Each dialogue set includes the four jug-event categories; no voice generation ran. `TruckTaxiWobbleVisual.BindPedestrian(utsRoot, bodyMaterial, detailMaterial)` is the visual-only hook after UTS spawn; `SetWobbleVisible(false)` restores original UTS visuals and is called before UTS ragdoll activation. UTS retains AI, skeleton, colliders, and ragdoll lifecycle.
