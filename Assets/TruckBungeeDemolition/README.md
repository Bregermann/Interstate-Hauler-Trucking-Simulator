# Truck Bungee Demolition

One to four simultaneous participants, three 60-second rounds, highest cumulative destruction score wins. Tied leaders receive equal 20-second extra rounds until resolved. Solo records a personal best. Each independent bay has a ten-storey, 50-module tower, actual GR3D truck, crane and bungee attachment.

Movement pumps the swing; the assigned action gives a short reel tug on a 3.5-second cooldown. Shared controller sticks have separate trigger actions. A genuine trapped/escaped truck is rehung with three seconds of lost control, preserving score. Whole controllers, shared sticks, keyboard clusters, AI, names and colors reuse the collection setup. Pause/reconnect preserves physical state; modal confirmation needs neutral/fresh input.

Core-Collapse **1.1**, product323012/upload771099, owns health, aggregate support capacity and cascading structural failure through Support and CollapserPrefrag. Truck Sports routes actual normal-speed impacts into ReceiveDamage, attributes secondary collapse, assigns fixed per-module budgets and stops all scoring at the timer cutoff. Rubble cannot farm points. Remaining supports are released during the shared finale with no further points; skip completes support release before advancing. Coarse physical fracture clusters include falling facade glazing. Pooled vendor dust is capped at256 particles per bay. The modeled crane mesh, prefab graph, materials, menu preview and saved scene are persistent; regeneration uses BungeeAuthoring.Create.

**Rope Toolkit dependency limitation:** no matching package was found in Assets, Packages/PackageCache or cached Asset Store package filenames. This implementation explicitly uses one SpringJoint as tension authority with an attached LineRenderer visual, bounded pumping/tug and speed limits. It does not claim a Rope Toolkit solver or rope/obstacle collision integration. No competing tension forces are added. The fallback produces a real free fall, stretch and rebound; replace its adapter with the actual vendor API only after importing and inspecting that package.

The GitHub repository is public. Newly imported commercial Core-Collapse source, meshes and textures are retained locally and excluded from source publication. A licensed checkout must import Core-Collapse1.1 with original GUIDs before compiling/opening these assets. Existing installed NWH, GR3D, Weather Maker, Heat, Cinemachine, RoadProps, ShipContainer and Scaffolds dependencies also remain required. No vendor source is modified. Wind, rope strain, physical impacts, siren and finale rumble reuse installed NWH/Weather Maker clips; shared settings and pause/focus/exit cleanup apply. Foreign rubble is explicitly filtered from other participants’ trucks and rubble, while own-bay collisions remain physical.
