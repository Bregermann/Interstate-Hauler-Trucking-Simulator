# Inferno Sleep/Wake visual authoring repair

2026-10-28. The actual retained V41 `action-Sleep-actual-playback.png` was inspected. Despite actual clip/bone playback, the dragon remained upright, with high wings and an awake-looking head. Functional animation contracts did not establish the required visible resting posture.

Read-only inspection of the real owned prefab's transform hierarchy established the principal issue: its limb/neck chains extend along local **negative X**. The earlier local Euler-X overlays largely twisted those axes rather than lowering the anatomy. The small generic pelvis-height offset also retained the upright body and raised source wing posture. No raw mesh, rig, FBX, material, imported animation or vendor controller was edited.

Explicit stopped native authoring entry:

`LWS.TruckDragonKingdom.DragonSpeciesAuthoring.UpgradeInfernoSleepWake()`

The selected species overload is `UpgradeGroundRestActions("dragon-inferno")`. Other rigs are deliberately rejected until reviewed separately. Existing `CreateCatalog()` now fills only missing authored action files; it preserves existing derivative curves. No Play Mode, import callback or normal build runs this upgrade.

The new project-owned partial `DragonSpeciesAuthoring.RestPose.cs` uses the actual Inferno Idle reference and exact original persistent prefab joint pose. It builds a forward/lowered torso, folds actual limb chains with two-bone geometry, lowers the actual three-joint neck/head toward the paws, folds the articulated wing chains against the body, curls the actual tail and adds subtle body/chest breathing. It measures the actual baked skin contact envelope instead of guessing an inactive renderer height. Wake begins at the same authored Sleep rest pose, then raises the head, torso and limbs and unfolds the wings into the actual source Idle pose. Sampling begins from the original source joint pose each time so unkeyed optimized FBX joints cannot accumulate previous temporary authoring offsets.

The upgrade generates both selected clips in memory first. It requires actual head/pelvis lowering and reduced wing span, and checks that Wake time zero matches Sleep time zero for every written joint. Invalid support/landmark checks stop before saving and report actual values. Existing selected private clip paths and GUIDs are retained. Only `Sleep.anim`, `Wake.anim` and their existing catalog mapping notes are saved; unrelated authored action file hashes must remain exact. Save operations target those assets individually rather than flushing unrelated dirty assets.

Actual native execution will write `RestPoseUpgradeReceipt.json` beside this document with the source FBX hash, selected before/after file hashes, actual joint/blend-shape counts, anatomical landmarks and the unrelated-action preservation result. That generated receipt does not exist merely because the source compiles.

After the updated base Sleep pose has been rendered and reviewed, an already composed Heist scene can explicitly call:

`LWS.TruckHoardHeist.Editor.HoardHeistAuthoring.RefreshSleepingVigilAfterRestReview(match)`

This derives its private curled-vigilance clip from the actual updated Sleep asset, preserves other existing Animator overrides and avoids nesting override controllers. It saves only the private vigilance clip/controller and marks the scene dirty for the lead's explicit save. New explicit Heist scene composition already derives the same clip through its original installation path. No Heist override has been regenerated by this workstream.

The inspected rig has no discovered eyelid bones; no material, eye texture or invented eyelid geometry was changed. Native authoring reports the real blend-shape count. Painted open-eye appearance therefore remains an explicit visual limitation unless actual supported controls are discovered. The new code must still pass actual source generation, contact-envelope checks, native Sleep/Wake playback and rendered inspection; compilation does not verify anatomy, folded-wing intersections, head/paw contact, eye expression or motor collider fit.
