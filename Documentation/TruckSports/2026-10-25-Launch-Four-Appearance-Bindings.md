Giant Swing, Field Goal and Beer Pong each reuse one physical truck between actual participant turns. Dock, Cornhole, Curling and Target are excluded from this implementation and require the separate contracts below.

The command does not open/save scenes, create vehicles, invoke a physics fitter or regenerate catalog content. It validates all actors before mutation, preserves existing complete registered hosts and refuses partial/custom bindings.

The audited source body has33 actual installed NWH GR3D meshes:29 body parts and the four Whl HD FL/FR/RL/RR meshes. The author verifies installed mesh identity and the already-authored SportsWheelMeshBinding indices before composing. Only that separate rendering subtree is bound. Sky's sail/straps/boat/cable, Swing's rig/seat/pivot/cables, Field Goal's ball/boot/tee/mechanism/posts and Pong's pads/coils/cups/table/floor stay protected. None of these four venues exposes an original dashboard/cab view; dashboard choices remain saved and the fit notice accurately marks the view unavailable rather than creating a camera/interior.

Sky's hosts have fixed slots0–3 and use the existing Session preparation and framing-cache refresh. Turn-based hosts are authored with slot−1 until their original attempt method assigns the actual Current/rules.Current owner. New `SportsLaunchAppearanceBoundary` is only explicit boundary glue, with no Update callback, camera/input/state machine or physical fitting. It uses the persistent participantId and original match color, then refreshes existing framing subjects.

Original replay.End occurs before owner preparation. Existing ResetFreshAppearanceRecord/RefreshAppearanceSources update the stopped record: first validate matching topology and copy actual rendering metadata, otherwise rebuild only the selected appearance source hierarchy through the existing adapter. Original ghost roots remain. Original model disposal detaches its old hierarchy before deferred Destroy, so removed body parts do not remain in the source traversal. Swing refresh happens at original LoadComplete before ResetRecord/first physical sample; FieldGoal/Pong refresh follows original equipment resets before ResetRecord; Sky's review refreshes physical truck indices0/2/4/6 at its existing new-match boundary. Boat indices and all nontruck sources retain their original bindings.

Source counts remain Swing2, FieldGoal3, Pong23 and Sky8. Original record capacities, intervals, masks, seeks, camera actions, Pong's physical-COM anchor, ring/cup/zone/field scoring and original launch/AI/physics code are preserved.
