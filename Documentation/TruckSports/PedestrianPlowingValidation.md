# Pedestrian Plowing implementation and validation

Two saved entries extend the existing collection: **Pedestrian Plowing** (shared arena, split chase or cab) and **Plowing · Cab Chaos** (forced full Taxi driver interior, live per-owner Compass GPS, animated steering/free look and existing Taxi jug challenge). One to eight competitors, at most four local humans, editable names/colors, independent Easy/Normal/Hard, shared keyboard/whole or opposite-stick controllers, solo score attack and AI-only matches use the existing offline lifecycle.

The city spans nine blocks on a 144m square, with connected EasyRoads streets, a plaza, alleys, installed buildings, festival canopies/stage/bunting, burning buildings and overturned burning cars. The default finite crowd contains240 original funny Taxi characters across five weighted models. Settings support16–384. Native NavMesh routes, crowd escape/social actions, existing jointed ragdolls, pooled impact dust and Core-Collapse props supply the physical play. Bonus/penalty roles use conspicuous gold stars/red STOP-cross uniforms, independently of skin/body/identity.

The sole PlowRound authority awards10/100/−100 on first meaningful actual solid contact, with pre-physics closing-speed qualification and contact-time ordering. Targets cannot score twice; negative scores and shared placing are supported. The three-minute round ends when positives are exhausted, ignoring surviving penalties. The final positive contact also blocks later same-step penalties. Results show each role count and sorted totals. Last-five positive targets receive beacons and a nearest-target direction/distance prompt.

Optional highlights record real truck/ragdoll transforms. Render-only ghosts contain no gameplay components or colliders; live actors are hidden/restored during the three-angle, .25/.5/1/2× playback. Recorded playback never changes sealed scores.

Standard targets additionally wear oversized blue cartoon costume noses. These are noncolliding role accessories, not changes to character skin or facial anatomy. Original character appearances remain independent of scoring roles. Near/distant rendering and jointed ragdolls retain the correct accessory visibility. Customization tools expose the owned prefab/material without changing Taxi sources.

Unsafe replay cloning invoked NWH lifecycle after removing its Rigidbody. Ghosts now copy only transforms/mesh render data. A Unity profiler clone-metadata crash was preserved separately; the stack does not establish a PhysX crash. Native validation disabled Editor profiler capture. Missing ScriptableObject dirty/save left an empty roster after restart; explicit save and start validation fix it. GPS public-property setup reset its physical screen transform; post-setup Taxi-coordinate fitting now maintains the actual live map. Per-view HUD backings are independent of the generic broadcast sizing. Runtime probe settings are cloned so deterministic tests cannot persistently disable normal randomized seeds. A replay speed assertion expected the wrong cycle value and was corrected. The added edit-time Cab validator now reads the serialized Canvas component instead of a runtime cache.

Native Mesh.CombineMeshes/LODGroup authoring combines the original flat-colored character geometry for distant rendering, retaining original detailed meshes nearby and restoring them before physical ragdoll. Skin/material identity is not selected by points. Custom textured/multi-material models retain full rendering. ## Customization and remaining human checks

Follow [the exact Inspector/spawn/model guide](PedestrianPlowingCustomization.md). Stop Play Mode before editing roster prefabs/weights, then re-enter the scene to rebuild that pool. Counts and role fractions apply on rematch; rematches reuse instantiated character bodies. Source checkouts require the existing licensed vendor packages, including the paths in PedestrianPlowingLicensedPrerequisites.json; original licensed packages are not republished. The Windows build includes required runtime content.

Human checks remain: driving/visibility and target readability in a dense moving crowd, subjective AI difficulty/fun, actual mixed keyboards/controllers/shared hardware, cab free-look comfort, jug challenge while driving, real haptics/audio balance, optional replay enjoyment and crowd-density tuning on the user's target PC. Recorded voice coverage is limited: existing matching audio plays only where installed; most funny character reactions are authored text rather than fully voiced dialogue.

Vendor audit: [concrete reuse and exclusions](PedestrianPlowingVendorAudit.md). No vendor source was edited and no replacement vendor framework was created.
