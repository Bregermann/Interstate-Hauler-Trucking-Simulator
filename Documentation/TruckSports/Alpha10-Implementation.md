## Integration

`SportsHitchesGames` owns stable catalog entries; `SportsFrontEnd`, `SportsNavigation`, `SportsCatalogue` and the existing saved menu launch their explicit scene paths. `SportsHitchesResults` adapts measured outcomes into the established typed result/report system. Failed objectives have no eligible first place. Cooperative modes produce team outcomes without individual winner points. No replacement lobby, profile database, keyboard, statistics service or telemetry backend was created.

Match setup uses existing participant IDs and sources. Results use existing Game Night winner points and profile statistics. Telemetry uses bounded `SportsSessionTelemetry.GameplayEvent` records: paddles, gates, capsizes, survival/objectives, haunt activity, hitches, measured throws, physical contacts, deliveries, fuel, cargo condition, chain depth and supported ice travel where implemented. The Windows software-controller probe has an opt-in two-new-sport path; it is not physical hardware verification.
