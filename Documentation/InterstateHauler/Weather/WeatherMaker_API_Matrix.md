# Weather Maker API Matrix

| Feature | Exact Vendor Class | Property/Method/Event | Vendor Prefab/Profile | Required Scene Components | How Interstate Uses It |
|---|---|---|---|---|---|
| Runtime singleton | DigitalRuby.WeatherMaker.WeatherMakerScript | IsPermanent, LastLocalProfile | Assets/WeatherMaker/Prefab/WeatherMakerPrefab.prefab | One WeatherMakerPrefab runtime | LwsWeatherMakerAdapter instantiates or resolves one global runtime. |
| Profile transition | DigitalRuby.WeatherMaker.WeatherMakerScript | RaiseWeatherProfileChanged(oldProfile, newProfile, transitionDuration, holdDuration, forceTransition, connectionIds) | WeatherMakerProfile_*.asset | WeatherMaker managers active under prefab | LWS preset requests transition the real vendor profile. |
| Resource lookup | DigitalRuby.WeatherMaker.WeatherMakerScript | LoadResource<T>(name) | Weather Maker ResourceContainer | Weather Maker runtime initialized | Adapter resolves named profile assets before falling back to AssetDatabase in Editor. |
| Camera binding | DigitalRuby.WeatherMaker.WeatherMakerScript | AllowCameras, AutoFindMainCamera, MainCamera | WeatherMakerPrefab | Active gameplay camera | Adapter registers the current gameplay camera and filters mirror/depth cameras. |
| Rain visuals | DigitalRuby.WeatherMaker.WeatherMakerPrecipitationManagerScript | Precipitation, PrecipitationIntensity, RainScript, RainIntensity | WeatherMakerProfile_LightRain, WeatherMakerProfile_HeavyRain, WeatherMakerProfile_Storm | Precipitation manager and rain script | LWS rain presets select Weather Maker rain profiles and set immediate intensity in instant mode. |
| Snow visuals | DigitalRuby.WeatherMaker.WeatherMakerPrecipitationManagerScript | Precipitation, PrecipitationIntensity, SnowScript, SnowIntensity | WeatherMakerProfile_LightSnow, WeatherMakerProfile_HeavySnow | Precipitation manager and snow script | LWS snow presets select Weather Maker snow profiles and set immediate intensity in instant mode. |
| Fog visuals | DigitalRuby.WeatherMaker.WeatherMakerFullScreenFogScript | FogProfile.FogDensity, FogProfile.MaxFogFactor | WeatherMakerProfile_MediumFog | Weather Maker full screen fog script | LWS fog presets use Weather Maker fog profile data and semantic visibility hints. |
| Clouds | Weather Maker cloud manager/fullscreen cloud scripts | CloudProfile, CloudCoverTotal diagnostic | Clear/cloud/overcast/storm profiles | Weather Maker cloud manager active | Profile transitions drive real Weather Maker cloud presentation. |
| Storm/lightning | Weather Maker thunder/lightning manager/script | LightningProfile, EnableLightning, CallNormalLightning/CallIntenseLightning available in vendor source | WeatherMakerProfile_Storm | Thunder/lightning manager active | Storm preset uses Weather Maker storm profile containing LightningProfile; no custom LWS lightning renderer. |
| Day/night | DigitalRuby.WeatherMaker.WeatherMakerDayNightCycleManagerScript | TimeOfDay, Speed, NightSpeed | WeatherMakerPrefab day/night manager | ILwsGameClockService and Weather Maker day/night manager | Adapter slaved vendor time to LWS game clock. |
| Quality | DigitalRuby.WeatherMaker.WeatherMakerScript | PerformanceProfile, AutoSetPerformanceProfile | Weather Maker performance profiles | Active URP scene | LWS quality tier adapter selects vendor quality where configured. |
