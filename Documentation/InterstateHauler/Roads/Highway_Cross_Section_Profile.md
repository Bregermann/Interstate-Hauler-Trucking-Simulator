# Highway Cross-Section Profile

## Runtime System

The highway validation baseline uses:

`Assets/LWS/InterstateHauler/Roads/Presentation/LwsInterstateRoadsideBuilder.cs`

Primary types:

- `LwsInterstateCrossSectionProfile`
- `LwsInterstateRoadsideBuilder`
- `LwsRoadsideRuntimeRoot`

## Default Validation Dimensions

| Element | Value |
| --- | ---: |
| Lanes per direction | 2 |
| Lane width | 3.7 m |
| Left shoulder | 1.2 m |
| Right shoulder | 3.0 m |
| Median | 14.0 m |
| Road surface Y | 0.55 m |
| Ground total width | 170 m |
| Outer slope width | 7.5 m |
| Ditch width | 5.0 m |
| Ditch depth | 0.85 m |
| Guardrail offset from road edge | 1.05 m |
| Guardrail height | 0.8 m |
| Guardrail collider height | 1.2 m |
| Guardrail max segment length | 160 m |

## Generated Elements

- Broad ground base with mesh collider.
- Median ground mesh with mesh collider.
- Left/right shoulder strips per carriageway.
- Outer slope and ditch strips.
- Physical guardrail cube segments with `BoxCollider`.
- `LwsRoadsideRuntimeRoot` diagnostics for generated counts.

## Scene Coverage

- TruckValidation: short straight validation roadside generated by the player truck spawner.
- InterstateCorridorValidation: roadside generated from the LWS road graph.
- StreamingHighwayValidation: roadside generated per streamed chunk and endless segment pool slot.
- IH_50MileFloatingOriginValidation: roadside generated per 50-mile chunk.

## Floating Origin

The roadside presentation is parented under each validation scene/chunk/root. Floating-origin shifts move those roots normally through the existing participant hierarchy; no separate world-coordinate authority is introduced.

## Production Notes

This is a validation cross-section, not final highway art. Prompt 016 and later world-building passes can replace the generated visuals with authored assets while keeping the same semantic cross-section and physical safety expectations.
